# Visualization of CNN

### LeNet · 神经网络全景可视化

**先看信号如何穿过整个网络，再看一个神经元究竟算了什么。**

[English](README.md)

这是一个用于理解卷积神经网络的交互式手写数字分类演示。页面保留完整网络全景，同时支持观察特征图、逐层播放前向传播，以及深入检查卷积、池化和全连接层的局部计算。

应用界面为英文。模型权重、示例数据、样式和 JavaScript 均内嵌于一个 HTML 文件中，无需后端、构建工具、GPU 或外部 JavaScript 库。推理和激活梯度计算在浏览器本地完成。

> 本项目使用 ReLU 和最大池化，是 **LeNet 风格的教学变体**，不是原始 LeNet-5 的严格复现。反向传播功能计算并展示梯度，**不会训练模型或更新权重**。

## 快速开始

下载并解压项目，使用启用 JavaScript 的浏览器打开 **`index.html`** 即可。

也可以在项目目录中使用 Python 3 启动本地静态服务器：

```bash
cd Visualization-of-CNN
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8000`。Python 仅用于这个可选的本地服务器，不参与模型推理。

较宽的电脑窗口更方便观察网络。小屏幕下可横向滚动局部计算面板；全屏功能是否可用取决于浏览器。

## 核心功能

- **完整网络全景：** 观察输入、卷积、池化、全连接和分类输出之间的信号传递，支持暂停和逐层播放。
- **神经元与特征图双视图：** 使用 `Neuron Network` / `Feature Maps` 切换，支持连接密度调整、平移、缩放和视角复位。
- **卷积计算放大：** 展示 5 × 5 输入窗口、卷积核、逐元素乘积、各通道求和、偏置及 ReLU 输出；支持滑动扫描。
- **池化与全连接检查：** 观察 2 × 2 区域取最大值，或选择全连接层神经元检查其计算。
- **反向梯度可视化：** 按所选目标标签计算交叉熵梯度，并向前面各层激活和输入像素传播。
- **内置样本与手写输入：** 40 个内置样本，每个数字类别 4 个；也可在画板中手写数字并执行本地推理。

## 建议的学习顺序

先选一个数字，关闭 `Auto sample`，用 `Next Layer →` 逐层观察。接着在局部面板选择 C1，使用 `Next Position` 或 `Scan Convolution`，观察同一个卷积核如何在不同位置生成输出。

随后切换到 C3，改变 `Input channel`：一个输出并非只来自一张输入图，而是汇总 6 个输入通道的 6 × 5 × 5 = 150 项乘积，再加一个偏置并经过 ReLU。最后检查 S2、S4 的池化，以及 F5、F6、OUT 的分类计算。

设置 `True label` 后点击 `← Backpropagate Error`。改变标签会改变损失和梯度，**不会改变预测结果**。

## 网络结构

空间张量使用“通道数 × 高 × 宽”表示。卷积核为 5 × 5、步长为 1、卷积不填充；最大池化窗口为 2 × 2、步长为 2。

| 层 | 操作 | 输出形状 |
| --- | --- | --- |
| INPUT | 灰度输入 | 1 × 32 × 32 |
| C1 | 卷积 1 → 6 + ReLU | 6 × 28 × 28 |
| S2 | 最大池化 | 6 × 14 × 14 |
| C3 | 卷积 6 → 16 + ReLU | 16 × 10 × 10 |
| S4 | 最大池化 | 16 × 5 × 5 |
| Flatten | 展平 | 400 |
| F5 | 全连接 400 → 120 + ReLU | 120 |
| F6 | 全连接 120 → 84 + ReLU | 84 |
| OUTPUT | 全连接 84 → 10，softmax 生成概率 | 10 类 |

内嵌权重和偏置共 **61,706 个参数**。

## 数据与模型说明

页面说明的数据来源为 **scikit-learn `load_digits` / UCI 光学手写数字数据集，并非 MNIST**。内置 8 × 8 样本的灰度值按 0–16 范围归一化，双线性放大至 28 × 28，再补零至 32 × 32。画板输入采用另一条预处理路径：裁剪笔迹、缩放、居中到 32 × 32 画布并归一化。

以下是 HTML 内嵌 `modelData.meta` **报告的训练信息**，不是重新训练并独立验证的结果：

| 项目 | 内嵌记录 |
| --- | --- |
| 训练样本数 | 1,437 |
| 测试样本数 | 360 |
| 随机种子 | 42 |
| 训练轮数 | 35 |
| 报告的测试准确率 | 98.89% |
| 打包的演示样本 | 40 个，每类 4 个 |

页面说明这些演示样本来自每类最先出现的四个测试样本，并非按是否识别正确挑选。本包未包含训练脚本、完整数据划分索引或完整测试集，不能据此完整复现上述训练结果。该准确率也不代表任意用户手写数字的识别率。

## 如何理解画面

**蓝色表示前向激活，红色表示梯度幅值，金色表示选中的局部感受野。**

为了保持可读性，全景中的节点和连线经过视觉采样，但数值计算使用完整网络。亮度在每层内独立归一化，因此不能直接跨层比较明暗大小。矩阵显示值经过四舍五入，计算使用底层数值。

反向传播从输出 logits 的交叉熵梯度 `p − one_hot(target)` 开始，继续传到前面各层激活和输入。红色不是权重更新、梯度正负号或输入图像重建。动画速度用于教学，不代表实际推理耗时。
