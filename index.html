Model, Data & Visualization Notes

This is a LeNet-style teaching variant with ReLU and 2×2 max pooling, not an exact reproduction of the 1998 LeNet-5. Convolution uses local receptive fields; pooling connects only to its corresponding 2×2 region. Spatial nodes and edges are visually sampled for readability, but forward values, probabilities, and gradients are fully computed in the browser. Brightness is normalized within each layer and should not be compared directly across layers. Displayed matrix values are rounded; computation uses full precision. Animation timing is pedagogical and does not represent actual compute time. Red encodes the magnitude of the cross-entropy gradient with respect to layer activations; it does not mean weights have been updated. This page never trains or modifies weights and never uploads drawn input. The label affects gradient computation only, not prediction.

References: PyTorch · LeNet-style network · scikit-learn · handwritten digits data
